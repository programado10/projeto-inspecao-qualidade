# Projeto de Inspeção de Qualidade

Mini-projeto desenvolvido no módulo de Machine Learning e Visão Computacional.

## Objetivo

Desenvolver um pipeline de visão computacional para análise de peças metálicas, utilizando técnicas clássicas de OpenCV e uma Rede Neural Convolucional para classificação de peças.

## Tecnologias

- Python
- OpenCV
- TensorFlow / Keras
- Matplotlib

## Status

Projeto em desenvolvimento.
